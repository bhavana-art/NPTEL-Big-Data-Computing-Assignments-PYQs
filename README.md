# Big Data Computing 📊

This repository contains **Previous Year Question Papers (PYQs), assignments, and solutions** for the Big Data Computing subject. It is intended to help students prepare for exams, complete assignments, and revise important concepts.

## 🎯 Purpose

- Make study materials easily accessible in one place.
- Help students prepare for internal and semester examinations.
- Provide reference solutions for assignments and practice questions.
- Encourage collaborative learning among students.
